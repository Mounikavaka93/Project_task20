# Nexus IT — Management Mobile UI

Mobile-first IT operations workspace built with React, Vite, and Tailwind CSS.

## Screens

- Splash / Welcome / Login
- Dashboard (stats, activity)
- Tickets (list + details + status)
- Tasks (priority, status, progress)
- Assets (inventory + details)
- Notifications, Profile, Settings

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (typically `http://localhost:5173`). On desktop the layout is framed like a phone; on a real device it fills the viewport.

Demo login accepts any email and password.
